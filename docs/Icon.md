# 明月新图标

资产 `assets/images/liquid-icon.png` 为 1254 × 1254 RGB 完整方形图标；`liquid-icon-foreground.png` 为同尺寸 RGBA 透明自适应前景。完整图标与前景已用于应用配置、启动画面和品牌页面。

生成方式：内置 ImageGen 首次生成完整图标，再以完整图标为参考进行透明背景编辑；未使用第三方生成 API。

最终提示词要点：浅瓷白和淡蓝全幅背景；中心一枚厚实、清透且微乳白的液体玻璃月牙，向右上开口；冷蓝轮廓、少量白色镜面高光和柔和接触阴影；正面视角、简洁，无文字、星星、脸部、外框或颗粒。透明版本保留同一月牙的材质和轮廓，去掉背景，标识约占画布 52%，为系统自适应裁切留出安全区域。

Android 背景色 #F6F8FC。单色主题图标采用前景 alpha 轮廓；系统按自己的遮罩和颜色显示。完整 PNG 可用于宣传或桌面图标，透明前景可用于界面及后续资源生成。
